# Active-active Multi-Data Center Database Architecture
## Percona XtraDB Cluster (PXC)

This repository documents the design, deployment, and validation of an
enterprise-grade active-active multi–data center database architecture
using Percona XtraDB Cluster.

## Key Capabilities
- Active–Active Multi-DC Architecture
- Synchronous Replication (Galera)
- High Availability & Disaster Recovery Ready
- Enterprise Monitoring with PMM
- Stress-tested up to 5000 concurrent threads
